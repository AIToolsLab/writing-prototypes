Writing Tools Prototypes

by Ken Arnold and the Thoughtful AI Tools Lab at Calvin University.

Two ways to do the same two things (highlight where the AI would write differently; predict what you might type next), both against a stock vLLM server:

  • Token-level: reads the model's next-token log-probabilities directly.
  • Structured: asks the model, via chat, to describe edits and suggestions as JSON.

Add ?server=https://your-vllm-host to use a different server. These pages send your text to that server, which may log requests; don't use sensitive information.
